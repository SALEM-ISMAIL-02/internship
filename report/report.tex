\chapter*{Abstract}\addcontentsline{toc}{chapter}{Abstract}
This report presents the design and implementation of \projectname{}, a web
learning platform for organizing training modules, teaching materials and
multiple-choice assessments. The project was completed during a one-month
professional internship. Its central objective was to provide a controlled
workflow from module publication to instructor approval of a learner's
assessment.

The solution combines Angular 21, Spring Boot 3.3, MySQL persistence,
document extraction strategies and Google's OpenAI-compatible Gemini API for
AI-assisted quiz generation. Instructors can create a quiz manually or
generate a draft from uploaded material, review and publish it, then inspect
the learner's answers question by question. A quiz is submitted only once and
the final certification state depends on instructor approval. JWT-based
authentication is integrated in the application security design and is
available as the authentication layer for the deployed project.

The report explains the context, requirements, architecture, data model,
implementation choices and validation process. It also discusses deletion
consistency, Swagger testing, user experience, limitations and future
improvements.

\noindent\textbf{Keywords:} e-learning; Angular; Spring Boot; MySQL; quiz;
artificial intelligence; JWT; document extraction; instructor approval.
